# Inspeção Visual Automática de Parafusos e Porcas

Projeto desenvolvido como atividade prática para a disciplina de **Aprendizagem de Máquina e Visão Computacional**, parte da Pós-Graduação em IA e Machine Learning.

#Objetivo
Desenvolver um sistema de inspeção visual capaz de detectar, identificar e contar automaticamente parafusos e porcas em imagens RGB, validando se o lote está conforme o padrão de qualidade industrial (10 unidades de cada).

#Tecnologias Utilizadas
- **Linguagem:** Python
- **Bibliotecas:** OpenCV, NumPy, Matplotlib

#Estrutura do Projeto
- `VC_Ativ1 (1).ipynb`: Notebook contendo todo o pipeline de processamento de imagem, desde o pré-processamento (filtros e detecção de bordas) até a contagem final das peças.
- `img01.jpg` a `img15.jpg`: Conjunto de imagens utilizado para validação e testes do algoritmo.

#Como Executar
O GitHub renderiza automaticamente o arquivo `.ipynb`. Você pode visualizar o código e os resultados diretamente no navegador clicando no arquivo `VC_Ativ1 (1).ipynb` na lista de arquivos deste repositório.

Para rodar localmente:
1. Certifique-se de ter Python instalado.
2. Instale as dependências: `pip install opencv-python numpy matplotlib`
3. Clone este repositório e execute o notebook em seu ambiente Jupyter.
